# SKYNAV (iPhone web)

Marine Sun sight — Home / Sight / Result. Offline after first load.

## Open on iPhone

1. Open the GitHub Pages URL in Safari (https required for camera and motion).
2. Share → **Add to Home Screen**.
3. Allow camera (rear) and motion when asked.

## Use

- **New sight — camera**: lock the horizon, then take several Sun shots. IMU must be ready; no invented Hs if the Sun is missing.
- **Enter Hs**: degrees + minutes (0–60) from a sextant.
- Honesty on screen: phone ~0.3–1° · sextant arc minutes.
- GPS is optional and only for assumed position (AP). Missing values show an em dash.

Sun only. No account. Works offline via the service worker.
